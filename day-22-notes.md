1.The difference between git add and git commit is git add is used to add the file or changes in a file and git commit is used to push the changes made from stging area to actual repo

2.The staging area basically keep track of all the changes included/added.Git just do not allow to commit directly because we can also stash the changes according to our need.

3.git log show the history of all the changes done

4.".git/" is a directory initiated by git when we ran git init. It comprises of all, the info about repo and we can rename the repo ,etc

5.working directory is the directory where we are currently working or implementing commands

staging area is like our draft before saving it permanently

repository is the place where we can find all the contents and files which are added by users
